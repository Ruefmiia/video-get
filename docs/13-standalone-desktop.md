## 范围与架构

桌面程序不再只是服务控制器。安装后可直接粘贴链接、分析、选择视频与画质、下载、查看任务、取消/重试、打开文件或下载目录，无需安装浏览器扩展。界面采用黑白灰和原生控件，网络操作在后台线程执行，主线程通过队列更新界面。

- 使用现有本机 FastAPI、yt-dlp、FFmpeg、SQLite；不部署云服务。
- 保留原回环端口 `17382`、Bearer Token、Native Messaging、扩展授权与接口。
- 桌面与扩展共享下载任务和默认目录 `%LOCALAPPDATA%\VideoGet\downloads`。
- 多视频帖子通过“视频”选择框逐个下载；不是 Android 的自动批量下载。
- 最近任务最多加载 50 条，每 1.5 秒刷新一次，不无限加载历史，不重复并发轮询。
- 修改/清空输入后立即失效旧分析结果；分析期间修改链接不会套用旧结果。
- 关闭主窗口缩到托盘，设置或托盘“退出”会停止自己启动的服务进程树。连接到其他实例的服务不会主动杀掉它。

## 当前平台边界

支持桌面核心已有的 X、Instagram 公开可访问视频和 B站普通投稿。B站支持 BV/av、b23.tv、指定分 P 和音视频合并。Instagram 需要登录的内容暂未增加桌面内登录；桌面不具备 Android 的全部图片/混合媒体功能。Threads 与 YouTube 桌面下载仍未实现，不因新增 UI 而自动支持。

## B站独立登录

1. 点击主窗口“B站登录”。
2. 在独立官方网页窗口中扫码或登录，凭据直接提交给 B站。
3. 检测到 SESSDATA 后，将必要会话 Cookie 同步给回环服务并关闭窗口，返回主窗口。
4. 重新分析链接，再选择账号实际可用的画质。
5. 设置内“清除 B站登录状态”清除服务内存会话；服务重启后需要重新登录。

实现使用 pywebview + Edge WebView2，在隔离子进程中运行，不混用 Tk 与浏览器事件循环。不向远程页面暴露自定义 Python/JS API，不读取外部浏览器配置，不保存账号密码或 Cookie 文件，不记录登录组件异常详情。只接受 B站根域根路径的四个必要 Cookie，排除其他域、过期及其他名称。

浏览器窗口使用私密模式；系统组件可能创建运行时缓存，不能承诺系统层面绝对无磁盘痕迹。服务凭证仍只保存在内存，不提供账号共享或分发功能。同步成功不等于账号权限已被源站确认，高清以实际分析结果为准。

登录窗口需要 Microsoft Edge WebView2 Runtime；缺少时程序提示打开微软官方下载页面。安装包包含 Python/FFmpeg 和登录集成库，不打包整套 Chromium。无需 Chrome/Edge 扩展，也无需用户安装 Python。

## 扩展仍可使用

扩展仍可在浏览网页时快速发起下载，以及主动同步该浏览器的 B站会话。两种登录入口更新同一服务会话，因此同步/清除后需要重新分析旧链接。不要在下载中途更换账号；如需立即停止会话使用，应取消下载。

## 构建与验收

```powershell
cd D:\Codex\video-get
python -m pip install -r apps/desktop-companion/requirements.txt
python -m pytest
.\apps\desktop-companion\build-installer.ps1
```

安装包：`apps/desktop-companion/dist/installer/VideoGet-Setup-0.2.1.exe`。

后端与桌面共 88 项测试通过，后端覆盖率 86.21%；扩展 32 项测试及类型检查通过，Ruff/mypy 通过。打包 EXE 的隐藏 Tk/WebView2 初始化、Cookie API、鉴权接口、FFmpeg 与公开视频分析下载已通过，ffprobe 确认合并文件包含视频与音频。

复测脚本：`python apps/desktop-companion/tests/smoke_packaged.py --download`。使用隔离目录及端口，完成后停止测试服务、删除测试媒体（此次测试文件 88,071,163 字节）。真实 B站账号扫码/高清、Windows 高 DPI 布局和覆盖安装仍需人工验收。不要将自动化回归等同于所有真实平台链接下载成功。
