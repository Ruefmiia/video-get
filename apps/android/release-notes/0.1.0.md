# Video Get Android 0.1.0

内部使用首版，仅维护 `arm64-v8a`。

## 已包含

- 手动粘贴和 Android 系统分享入口。
- X、Instagram 与公开 Threads 链接识别。
- 设备内 yt-dlp/FFmpeg 分析、下载和后处理。
- X 公开媒体回退解析。
- Threads 正式链接、分享链接、轮播及嵌套/引用媒体。
- WorkManager 前台下载、进度、取消和 MediaStore 保存。
- 文件保存到 `Movies/Video Get`。

## 0.1.0 冒烟结果

- 签名、SHA-256、Release 构建和 Release Lint 通过。
- `arm64-v8a` 真机全新安装、同签名覆盖安装和启动通过。
- X 分享、分析、格式选择和下载完成。
- Threads 嵌套媒体分享、分析和下载完成。
- 测试期间未出现 AndroidRuntime 崩溃。
- Instagram 回归 Reel 当前被源站判定为需要登录；错误提示正常，但本轮未确认公开 Reel 成功下载。

## 已知限制

- 不读取浏览器或其他 App 的 Cookie，不支持私密、登录后可见或受访问控制的内容。
- 部分纯 JavaScript 动态 Threads `xmt` 页面可能超时或无法确认目标媒体。
- 仅提供分离 DASH 音视频轨道的 Threads 帖子尚未全部支持合并。
- 暂无下载历史、多任务队列和 Room 持久化。
- 社交平台页面结构和访问策略变化可能导致个别链接失效。
- 当前日常发行只更新 `arm64-v8a`；其他 ABI 保留兼容基线，按需更新。

## 安装与升级

- 从旧 Debug 签名首次切换到本版本时必须卸载旧 App，再安装 Release APK。
- 从本版本开始，后续版本必须使用同一内部签名密钥并递增 `versionCode`，即可覆盖升级。
- APK 包含 GPL-3.0 组件，发行物同时提供 `THIRD_PARTY_NOTICES.md`；密钥、密码和 JKS 不随 APK 分发。
