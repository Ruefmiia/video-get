# Video Get Android 1.0.0

> 首个正式内部版本。默认发行架构为 `arm64-v8a`。

## 平台能力

- YouTube：普通视频、`youtu.be` 短链接与 Shorts 单视频。
- X：公开帖子视频，支持一个帖子内多个视频顺序批量下载。
- Instagram：App 内网页登录、Reel、单图、轮播多图和图文/视频混合帖子。
- Threads：公开单视频、轮播、嵌套/引用媒体及分享链接。

## 使用体验

- 支持手动粘贴和 Android 系统分享入口。
- 提供媒体分析、画质选择、下载进度、取消、重试和任务恢复。
- 下载完成后可打开媒体或对应保存目录。
- 图片保存到 `Pictures/Video Get`，视频保存到 `Movies/Video Get`。
- 新增黑白猫咪简笔画自适应启动图标。

## Instagram 登录与隐私

- 登录凭据只输入到 Instagram 官方网页，Video Get 不读取账号密码。
- 检测到有效登录会话后自动返回主界面。
- 分析和后台下载使用当前 WebView 会话；临时 Cookie 文件在单次调用后删除。
- 不读取 Chrome 或 Instagram App Cookie，不上传登录凭据，Android 数据备份已关闭。

## 修复

- 修复普通 yt-dlp 格式的空直链被当成字符串 `null`，导致 `getHost(...) must not be null`。
- 修复 Android 14+ WorkManager 前台服务类型崩溃。
- 修复 X 多视频帖子只能下载第一个视频。
- 修复部分 Threads 分享页、动态页面及嵌套媒体解析问题。

## 已知限制

- 登录会话可能因 Instagram 风控、验证码或账号安全操作失效，需要重新连接。
- 不支持 DRM、私密或无权访问的内容，也不绕过平台访问控制。
- Threads 纯动态页面和分离 DASH 媒体仍可能因平台结构变化失败。
