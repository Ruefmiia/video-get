# Video Get Android 0.2.0

> 验证状态：Debug 自动化、签名 Release 覆盖安装和 YouTube 公开视频真机下载通过。

## 新增

- 支持 YouTube 普通视频、`youtu.be` 短链接和 Shorts 单视频链接。
- 支持从 YouTube App 分享链接后自动分析。
- 提供最佳兼容画质、最高 1080p 和最高 720p。
- 优先选择 MP4/H.264 与 M4A，并使用 FFmpeg 合并分离音视频。
- 合并阶段显示“正在合并音视频”。
- 增加 YouTube 私密、会员、登录、地区、直播、403 与 JS 组件错误提示。
- 用户主动分析 YouTube 时，每 24 小时最多检查一次 yt-dlp 官方 stable 更新，避免内置解析器过期。
- 下载失败时优先展示最终错误，不再用 yt-dlp/SABR 警告遮盖原因。

## 边界

- 不支持播放列表、批量下载、直播、账号 Cookie、会员/私密内容或 DRM。
- YouTube EJS 挑战脚本按需从 yt-dlp 官方 GitHub 组件源获取。
- yt-dlp 不在后台更新；仅在用户主动分析 YouTube 时检查官方 stable 更新。
